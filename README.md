# 🧮 Calculator App

A simple and attractive **Calculator Web App** built using **HTML, CSS, and JavaScript**.  
It provides an easy-to-use interface for performing basic mathematical calculations with a stylish design and customizable background.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal calculations
- 🧹 Clear input
- 🗑️ Clear All option
- 🖼️ Change Background feature
- 🎨 Simple and attractive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📌 About the Project

This project was created to practice JavaScript fundamentals and DOM manipulation.  
The calculator allows users to enter numbers, select mathematical operators, calculate results, clear values, and change the background of the webpage.

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start using the calculator.


## 🎯 Purpose

The main purpose of this project is to improve front-end development skills and understand how JavaScript can be used to create interactive web applications.
